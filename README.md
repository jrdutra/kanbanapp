# Kanban App 🗂️  
[https://KanbanApp.io](https://kanbanapp.io)
**Kanban Board | Task Manager | Productivity Tool | HTML, CSS, JavaScript**

Kanban App is a lightweight **Kanban board** for task management and productivity, built with **pure HTML, CSS, and JavaScript**.  
O Kanban App é um **gerenciador de tarefas estilo Kanban**, leve e moderno, desenvolvido em **HTML, CSS e JavaScript puro**.

---

## 🌎 Live Preview / Visualização

Open the `index.html` file in your browser.  
Abra o arquivo `index.html` no navegador.

---

## ✨ Features / Funcionalidades

### 🇺🇸 English
- Drag & drop columns and cards
- Checklist with automatic progress bar
- Due dates with color rules
- Filter cards by title or description
- Creation and last update timestamps
- Sort by date and group by status
- Export and import board as JSON
- Modern dark mode UI
- No frameworks required

### 🇧🇷 Português
- Arrastar e soltar colunas e cards
- Checklist com barra de progresso automática
- Datas de vencimento com regras de cores
- Filtro de cards por título ou descrição
- Registro de criação e última edição
- Ordenação por data e agrupamento por status
- Exportação e importação em JSON
- Interface moderna em modo escuro
- Sem uso de frameworks
